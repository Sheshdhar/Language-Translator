# Lingua Translator

A responsive translation app with automatic language detection, a language selector, and a copyable translation result.

## Run

Open `index.html` in a modern browser. An internet connection is required for translation.

## Features

- Translate between 90+ commonly used languages.
- Detect the source language automatically or select it yourself.
- Swap languages, clear text, and copy the result.
- Translate with the button or press `Ctrl+Enter` (`Cmd+Enter` on macOS).
- Responsive layout for desktop and mobile screens.

Automatic detection and translation use Google's publicly accessible translation endpoint. The app needs an internet connection, and the online service may have usage limits or change availability.
